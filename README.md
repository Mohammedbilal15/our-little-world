# For You ❤️

A romantic interactive website made with HTML, CSS and JavaScript.

## What is interactive

The opening screen, smooth navigation, flip cards, secret message, photo cards, open when messages and final celebration all use JavaScript.

## Add photos easily

1. Put your JPG or PNG files inside the `photos` folder.
2. Open `photos/photoLinks.js`.
3. Add each photo to the list with its file name, title and caption.
4. Upload the folder to GitHub.

Example:

```js
{ src: "photos/our_photo.jpg", title: "Our photo", caption: "A memory I will always keep ❤️" },
```

## Publish on GitHub Pages

Create a repository and upload `index.html` plus the `photos` folder. Then open Settings, Pages, choose Deploy from a branch, select the main branch and root folder, and save.
