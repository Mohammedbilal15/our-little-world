HOW TO ADD PHOTOS

1. Put your JPG or PNG photos in this folder.
2. Open photoLinks.js.
3. Add one line for each photo using this format:

{ src: "photos/our_photo.jpg", title: "Our photo", caption: "A memory I will always keep ❤️" },

4. Save everything and upload the folder to GitHub.

The website will automatically create the photo cards and make each photo clickable.
